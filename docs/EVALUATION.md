# Evaluation

## Question
How can a transparent digital twin quantify temperature excursions and cooling-control trade-offs under varying ambient profiles?

## Metrics
- Maximum temperature
- Excursion duration
- Cooling-energy proxy
- Temperature trajectory
- Sensitivity to ambient regime

## Falsification
- Cooling increases temperature under identical conditions.
- Excursion time is counted below threshold.
- State time fails to advance consistently.
