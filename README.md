# Cold Chain Digital Twin

A software-only cold-chain simulation for exploring temperature drift, cooling control and excursion alarms.

## Implemented
- first-order thermal model
- ambient temperature influence
- configurable cooling power
- time-step simulation
- threshold excursion detection
- summary statistics
- deterministic tests

## Boundary
This is a synthetic digital-twin model. It does not ingest real IoT sensors, certify pharmaceutical/food compliance, or model every physical effect.
